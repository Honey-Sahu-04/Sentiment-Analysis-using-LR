Sentiment analysis using Logistic Regression
\nDataset used: Sentiment140
\nDataset Link: https://www.kaggle.com/datasets/kazanova/sentiment140

To run the chatbot:
- Make sure Python3 is installed
- Install streamlit using "pip install streamlit"
- Keep chatbot.py and the two pickle files in the same folder and use the command "streamlit run chatbot.py"

To run the codes in code.ipynb without errors:
- Make sure Python3 is installed
- Install pandas, pickle and scikit-learn using "pip install pandas pickle-mixin scikit-learn"
